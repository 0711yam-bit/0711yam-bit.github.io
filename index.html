17猫団ライブ配信（17 Neko-dan Live）

「17（いちなな）猫団」は、17匹の猫たちの日常をお届けするYouTubeチャンネルです。このページは、チャンネルのライブ配信を運営するために作った小さなツール「17猫団ライブ配信」の公式ページです。

YouTubeチャンネル: 17（いちなな）猫団

このツールについて

このツールは、チャンネル運営者本人が自分のYouTubeチャンネルのために使う個人用ツールです。YouTube Data APIを使って、次のことだけを行います。

  • ライブ配信の枠（ライブイベント）を作成・設定する
  • 自分のチャンネルの登録者数を取得し、ライブ映像に表示する

English

"17 Neko-dan Live" is a small personal tool used by the owner of the YouTube channel "17 Neko-dan" to run the channel's 24-hour live stream. It uses the YouTube Data API only to create and configure the channel's own live broadcasts and to read the channel's own subscriber count for an on-screen counter. It is not offered to the public and does not access any other user's data.
